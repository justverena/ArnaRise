# ArnaRise

**ArnaRise** — это безопасная и удобная веб-платформа для централизованного сбора, хранения и анализа отчётов по вопросам гендерного равенства.  
Система помогает организациям управлять данными и отслеживать ключевые гендерные показатели с помощью интерактивных дашбордов, ролевого доступа и автоматической агрегации данных.

---

## Описание проекта

ArnaRise упрощает процесс сбора и анализа данных о гендерном равенстве между различными организациями и регионами.  
Платформа позволяет партнёрам отправлять структурированные отчёты, аналитикам — проверять и утверждать их, а администраторам — управлять пользователями и ролями.  
Всё это — в одной интегрированной системе.

---

## Основные возможности

- **Ролевая система** — роли администратора, аналитика и партнёра с разными уровнями доступа  
- **Управление отчётами** — создание и отправка отчётов по шаблонам  
- **Модерация данных** — аналитик может одобрять или отклонять отчёты с указанием причины  
- **Интерактивные дашборды** — визуализация агрегированных гендерных показателей  
- **Фильтры и аналитика** — по категориям, районам, полу и временным периодам  
- **Модули машинного обучения** — классификация, агрегация и прогнозирование ключевых метрик  
- **Двуязычный интерфейс** — поддержка казахского и русского языков  
- **JWT-аутентификация** — безопасный доступ к API  
- **CI/CD и контейнеризация** — запуск через Docker и Docker Compose  

---

## Технологический стек

**Backend:** Java Spring Boot, Spring Security, JPA (Hibernate), PostgreSQL  
**Frontend:** Vue.js 3, Pinia, Vue Router, i18n
**Инфраструктура:** Docker, Docker Compose
**Тестирование:** JUnit 5, Mockito, Jest
